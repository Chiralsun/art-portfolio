# Art portfolio website
a full stack art portfolio website built with the MERN stack (MongoDB, Express.js, React, Node.js)

features:
uploading artwork with images
filter by medium style and date
gallery view with lightbox
search functionality


# Tech Stack

- **Frontend:** React, Vite, React Router, Axios
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **File Upload:** Multer, Sharp
- **Styling:** CSS

## Installation

### Prerequisites

- Node.js (v16 or higher)
- MongoDB (local or Atlas)
- npm or yarn

### Backend Setup

\`\`\`bash
cd backend
npm install
cp .env.example .env
# Update .env with your MongoDB URI
npm run dev
\`\`\`

### Frontend Setup

\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
